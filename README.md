# Ashure Enhance #

Ashure Enhance es una aplicación web desarrollada para mejorar la resolución y nitidez de fotografías e ilustraciones mediante modelos de aprendizaje automático ejecutados directamente en el navegador.

El proyecto permite escalar imágenes en 2x y 4x, ajustar la reducción de ruido y seleccionar el formato de salida. Utiliza WebGPU para acelerar el procesamiento cuando está disponible, con una alternativa basada en WebAssembly.
